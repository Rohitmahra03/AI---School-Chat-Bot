Node.js Express + Groq API Secure Integration Files

Zero Client-Side Secret Exposure

In accordance with high-level web security standards, the frontend never makes direct requests to the Groq endpoints with an embedded token. All queries are channeled to a Node.js Express backend proxy that securely loads GROQ_API_KEY from a local .env file.

// server.js - Secure Node.js + Express Backend Proxy for Groq API
require('dotenv').config();
const express = require('express');
const cors = require('cors');
const path = require('path');

const app = express();
const PORT = process.env.PORT || 3000;

// Security & Middleware
app.use(cors());
app.use(express.json());
app.use(express.static(path.join(__dirname, 'public')));

// School Tutor System Prompt

You are EduBot, an exceptionally encouraging, kind, and knowledgeable school tutor for students in grades 6 through 12.
Key behavioral rules:
1. Explain concepts step-by-step with clear numbered points.
2. Adapt vocabulary to be simple, engaging, and clear for school students.
3. For Math and Physics: show formulas, identify knowns/unknowns, and demonstrate step-by-step derivations.
4. For Chemistry: provide balanced equations, state symbols, and practical real-world relevance.
5. Multilingual fluency:
   - For questions in Hindi, answer in clean, polite Hindi.
   - For English questions, respond in English.
   - For Hinglish queries, explain naturally in Hinglish to help students connect.
6. If a question is ambiguous, ask guiding clarification questions.
7. Always emphasize deep conceptual understanding rather than rote memorization.
8. End with a short encouraging remark or study tip.
`;

// Chat API Endpoint
app.post('/api/chat', async (req, res) => {
  const { messages } = req.body;

  if (!messages || !Array.isArray(messages)) {
    return res.status(400).json({ error: 'Messages array is required.' });
  }

  const apiKey = process.env.GROQ_API_KEY;
  if (!apiKey) {
    return res.status(500).json({
      error: 'GROQ_API_KEY is not configured on the server. Please check your .env file.'
    });
  }

  try {
    const payload = {
      model: 'llama3-70b-8192', // Fast, high-reasoning Groq model
      messages: [
        { role: 'system', content: SCHOOL_TUTOR_SYSTEM_PROMPT },
        ...messages
      ],
      temperature: 0.5,
      max_tokens: 1500
    };

    const response = await fetch('https://api.groq.com/openai/v1/chat/completions', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${apiKey}`
      },
      body: JSON.stringify(payload)
    });

    if (!response.ok) {
      const errData = await response.json().catch(() => ({}));
      return res.status(response.status).json({
        error: errData.error?.message || 'Groq API returned an error.'
      });
    }

    const data = await response.json();
    const reply = data.choices[0]?.message?.content || 'No response generated.';
    
    return res.json({ reply });
  } catch (error) {
    console.error('Server error handling /api/chat:', error);
    return res.status(500).json({ error: 'Internal server error while connecting to AI service.' });
  }
});

app.listen(PORT, () => {
  console.log(`EduBot Server running at http://localhost:${PORT}`);
});

# 🎒 AI School Chatbot (Groq Powered)

A modern, responsive, school-themed AI assistant for students covering Math, Science, Languages (Hindi, English, Hinglish), and Computer Science.

## 🚀 Quick Start Instructions

1. **Clone or extract the repository**:
   ```bash
   cd ai-school-chatbot
   npm install
   ```

2. **Configure your API Key**:
   - Copy `.env.example` to `.env`:
     ```bash
     cp .env.example .env
     ```
   - Open `.env` and paste your free Groq key from [Groq Console](https://console.groq.com/keys).

3. **Start the local server**:
   ```bash
   npm start
   ```
   Open your browser at `http://localhost:3000`.

## 🛡️ Security Architecture
- The Groq API key is guarded entirely inside the Node.js process via `process.env.GROQ_API_KEY`.
- No tokens are ever sent to or readable in the browser client.
